### Общие параметры для настройки логирования:
Уровень  INFO:
+ Заказ создан (user_id, order_id, timestamp)
+ Исполнитель назначен (order_id, operator_id, timestamp)
+ Заказ взят в работу (order_id, operator_id, timestamp)
+ Заказ отменён пользователем (order_id, timestamp)
+ Заказ просрочен (order_id, operator_id, timestamp)
+ Заказ успешно выполнен (order_id, timestamp)

### Мотивация:
+ Логирование позволяет нам заглянуть в прошлое системы
+ Логирование освобождает разработчика от постоянного мониторинга системы.
+ Логирование может помочь увидеть потенциальные проблемы, еще до того как их заметит пользователь

### Предлагаемое решение:
Поскольку предлагается логировать жизненный цикл заказа, то нужно настроить логирование прежде всего для следующих систем:
1. Internet Shop
2. Shop API
3. MES API
4. CRM API
5. MES db

Для записи логов, их организации и управления ими - предлагается использовать стэк ELK
В компоненты системы предполагается добавить библиотеки для логирования (в зависимости от стэка и знаний и предпочтений команды)

### Обеспечение безопасности:
1. Не храним в логах лишних данных, а так же личных данных пользователей
2. Не храним в логах данных обеспечивающих безопасность системы (токены, пароли)
3. Ограничиваем доступ к логам только для авторизованных пользователей
4. Используем шифрование логов при передаче
5. чувствительные, но нужные данные - нужно маскировать

Поскольку логи касаются только жизненного цикла заказа, то хранить их предполагается не больше месяца
Хранить только те логи, которые связаны с актуальными, просроченными или отмененными заказами
Предполагается, что если заказ выполнен, то логи, связанные с ним - удаляются
При возникновении критических ошибок или аномалий - предполагается алертинг. Для этого предлагается использовать Prometheus Alertmanager

**Предлагаемая схема работы логирования:**
1. компонент при совершении, действий с заказом, генерит логи через библиотеку (выбранную командой)
2. Отфильтровывает, а затем логи отправляет в Elastic Search Db
3. Kibana (часть стэка ELK) - предоставляет интерфейс для визуализации логов
